Pequeño programa desktop para administrar enfrentamientos entre boxeadores amateurs y exhibiciones.
Se ingresan los peleadores y sus características y el sistema los clasifica según las mismas y separa los posibles rivales.
El usuario genera los emparejamientos.
El programita web esta diseñado para mostrarse en un monitor/TV que le muestre a los asistentes al evento el orden de las peleas, resaltando la pelea en curso.
Es un programa portatil, por ende utiliza una base de datos de sql lite.
